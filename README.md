# 📊 Análise de Dados e Automação em Python

Este repositório reúne projetos práticos, rotinas de tratamento de dados e visualizações focados no estudo e aplicação de análise de dados com Python.

## 📁 Estrutura do Repositório

- `projeto_vendas.py`: Script de análise de dados focado no processamento de receitas, volume de vendas e métricas por produto/categoria.
- `grafico_receita_categoria.png`: Visualização gráfica da distribuição de receitas por categoria de produto.
- `grafico_receita_produto.png`: Visualização detalhada do desempenho e faturamento por produto individual.
- `conclusoes.txt`: Relatório com *insights* de negócio e conclusões extraídas a partir da análise dos dados.
- `ola_mundo.py`: Script de testes e validação de ambiente de desenvolvimento.
- `requirements.txt`: Dependências do projeto para replicação do ambiente de execução.

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Python 3
- **Manipulação e Análise de Dados:** Pandas
- **Visualização de Dados:** Matplotlib / Seaborn
- **Controle de Versões:** Git & GitHub
